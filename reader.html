What this is

simple astro is a set of handouts working through the International Olympiad on Astronomy and Astrophysics theory syllabus, one topic at a time — written to build intuition first, with the formalism arriving because it's needed, not before.

The sidebar mirrors the syllabus's own structure: seven content sections, each broken into the same subtopics IOAA itself lists. Guides are added as they're written, so some entries are live and some are still blank pages — open one and you'll see which.

How to read them

Each guide assumes the prerequisite knowledge stated at its start and builds forward from there — Newton's laws and basic calculus are usually assumed; anything more specialized is derived, not assumed. They're meant to be read in order within a section, but every guide can also stand alone as reference.
